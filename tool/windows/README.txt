Particle Library for Windows
============================

Run ParticleLibrary.exe from the extracted folder. Keep the EXE, DLLs, and
data directory together.

The installer runs per user. To uninstall, delete its installation folder
and its Start Menu and desktop shortcuts.

The included PDG snapshot is verified on first launch. Notes, settings,
favorites, and downloaded reviews are stored in your Windows user profile.
