## Description

Particle Library is an offline app for the Particle Data Group Review of
Particle Physics, with notes, references, PDF reviews and annotations.

Browse particles, decays, measurements and references from the bundled PDG 2026
snapshot. Create local Markdown notes anchored to PDG entries, references or PDF
highlights; organize them with tags and collections; and search everything
offline. Download official PDG review PDFs on demand, highlight text, and keep
the highlight as a normal searchable note.

The app is independent and not affiliated with the Particle Data Group. PDG data
are used under CC BY 4.0 with attribution.
