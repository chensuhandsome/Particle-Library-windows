# 数学表示转换说明

本文档记录 PDG 文本中的数学记法、转换语法、已验证样例，以及“无法完整解析时保留原文”的回退策略。实现位于：

- `lib/domain/pdg_math.dart`：PDG 文本表达式解析器（纯 Dart，可单测）。
- `lib/domain/latex.dart`：粒子名转换、文本分段器 `segmentPdgText`、完整文本中的 `$...$`/箭头处理。
- `lib/features/common/description_text.dart`：把文本段渲染为 `Text.rich` + `Math.tex`（`flutter_math_fork`）。

## 1. 输入形式

PDG 快照里的文本不是 LaTeX，主要有三种形式：

1. **真正的 TeX 片段**：文献标题中的 `$...$`，例如 `$B_s^0$`、`$WZ$`。
2. **粒子名/性质名**：例如 `B_s^0`、`K(S)0`、`D_s()+-`、`D_1(2420)0`。
3. **PDG 说明文本里的 ASCII 数学**：例如 `g**nu_{{{{\mathit \ell}}}}`、`g(A)**e`、`sin**2(2theta(14))`、`mass**2(pi)`、`10**-6`。

`**` 在 PDG 文本中表示上标，**不是 Markdown 加粗**；`_` 表示下标。

## 2. 已核对的关键语义

PDG 的原始 listings 给出了这些表达式的实际排版。已逐项核对：

- Z 玻色子：`https://pdg.lbl.gov/2022/listings/rpp2022-list-z-boson.pdf` 第 42 页
- π⁰ 电磁形状因子：`https://pdg.lbl.gov/2022/listings/rpp2022-list-pi-zero.pdf`
- 中微子混合：`https://pdg.lbl.gov/2022/listings/rpp2022-list-neutrino-mixing.pdf`
- top quark EW couplings：`https://pdg.lbl.gov/2022/listings/rpp2022-list-t-quark.pdf`

关键对照：

| 源文本 | 正确排版 | 说明 |
|---|---|---|
| `g**nu_{{{{\mathit \ell}}}}` | $g^{\nu_{\ell}}$ | `**` 的操作数是整个 `nu_{...}`；ℓ 是 ν 的下标（下标嵌在上标里），不是 g 的下标 |
| `g**nu_{e}` | $g^{\nu_{e}}$ | 同理，e 嵌在 ν 的上标内 |
| `g(A)**e` | $g_{A}^{e}$ | 括号 A 是 g 的下标，`**e` 是 g 的上标 |
| `g(V)**e` | $g_{V}^{e}$ | 矢量耦合 |
| `f(1)**L` | $f_{1}^{L}$ | 括号 1 是下标，L 是上标；top listings 直接验证 |
| `K(S)0` | $K_{S}^{0}$ | K 的 S 下标 + 0 电荷 |
| `K0S` / `K0L` | $K_S^0$ / $K_L^0$ | PDG 的扁平写法；整段公式和测量说明都适用 |
| `eta'` / `eta^'` | $\eta'$ / $\eta^{\prime}$ | prime 后缀 |
| `D_s()+-` | $D_{s}^{\pm}$ | 空括号是质量占位；`+-` 是电荷 |
| `D_1(2420)0` | $D_{1}(2420)^{0}$ | 下标 1、质量 2420、电荷 0 |
| `H_{{1}}()0` | $H_{1}^{0}$ | 同类 |
| `mass**2(pi)` | $m_{\pi}^{2}$ | PDG 把 mass(X) 排成 $m_X$；不是直立的 `mass` 函数；π⁰ listing 直接验证 |
| `sin**2(2theta(14))` | $\sin^{2}(2\theta_{14})$ | 中微子 listings 实际排成 $\sin^2(2\theta_{12})$ |
| `mass(e+ e-)/mass(pi0)` | $m_{e^+e^-}/m_{\pi^0}$ | π⁰ listings 实际排成 $[m_{e^+e^-}/m_{\pi^0}]^2$ |
| `G(Z --> J/psi(1S) lepton+ lepton-)` | $\Gamma(Z\to J/\psi(1S)\ell^+\ell^-)$ | `G(...)` 是宽度函数，`lepton` 是通用轻子 $\ell$，`J/psi` 是 $J/\psi$ |
| `nu_lepton` | $\nu_{\ell}$ | 轻子味下标 |
| `sqrt(W**2)` | $\sqrt{W^{2}}$ | `sqrt` 使用 `\sqrt{...}` |
| `10**-6` | $10^{-6}$ | 数字指数 |
| `B_s^0` | $B_{s}^{0}$ | 粒子名 |
| `$B_s^0$` | $B_{s}^{0}$ | 直接 TeX |

> 注意：`g**nu_{e}` **不是** $g^{\nu}_{e}$。PDG PDF 中 e/ℓ 位于 ν 的上标内部；解析器按右结合规则处理 `**`。

## 3. 解析语法

### 3.1 `**` 右结合

```
expr      := atom suffix*
atom      := command | word | number | '(' expr ')'
suffix    := '_' script | '^' script | '**' script | '(' group ')' | charge
script    := '{' expr '}' | atom
```

`**` 的 script 是**一个完整 atom**，包括它自己的下标。因此：

- `g**nu_{e}` → `g^{ν_{e}}`
- `q**2` → `q^{2}`
- `g(A)**e`：`(A)` 先作为 g 的下标，`**e` 再作为 g 的上标。

### 3.2 括号的三种角色

解析器不猜测；只在角色明确时转换：

1. **函数参数**
   - 函数名：`mass`、`Gamma`、`G`、`B`、`A`、`N`、`R`、`S`、`T`、`sin`、`cos`、`tan`、`sqrt`、`log`、`exp`、`Sum`、`sum`、`Abs`、`max`、`min`、`d`。
   - `mass(X)` 是特例：PDG 排成 $m_X$，所以 `mass(pi0)` → $m_{\pi^0}$，`mass(e+ e-)` → $m_{e^+e^-}$，`mass**2(pi)` → $m_{\pi}^{2}$。
   - 例：`R(K)**-`、`sin**2(theta(23))`。
2. **耦合/量子数下标**
   - `g(A)`、`g(V)`、`f(1)`、`f(2)`、`h(1)` 等。
   - `K(S)`、`K(L)` 中的 S/L。
   - `theta(12)`、`theta(13)`、`theta(23)` 等角度下标。
3. **质量标签**
   - 纯数字或 `1S/2S/...`：`D_1(2420)0`、`B(5279)`。
   - 空括号只是占位，显示时省略：`D_s()+-`、`F_0()`。

如果括号内容无法归入以上任一类，整个表达式回退原文，不猜成下标或函数参数。

### 3.3 电荷后缀

粒子名后的 `+`、`-`、`+-`、`-+`、`0` 作为上标电荷：

- `D0` → `D^{0}`
- `pi+` → `\pi^{+}`
- `D_s()+-` → `D_{s}^{\pm}`

如果同一层级已经有一个上标，再出现电荷/第二个 `**` 会拒绝整个表达式，避免生成非法的双上标（例如 `pi**0+` 保留原文）。

### 3.4 文本命令

- `\mathit`、`\rm` 只是字体命令；解析时去掉。
- `\ell`、`\nu`、`\mu`、`\tau`、`\Gamma`、`\pi` 等命令原样进入 LaTeX。
- `\bar{\nu}` 等命令组只在能够完整闭合时使用。
- 不执行任意 LaTeX；遇到 `\frac` 等未完整支持的组合，整段回退原文。

### 3.5 `$...$` 与箭头

- `$...$` 直接作为 TeX 数学段，交给 `Math.tex`；不经过 ASCII 解析器。
- 文本中的 `-->`、`->`、`→` 转成 `\longrightarrow`。
- 引用标题、章节说明、脚注、测量说明、性质标题、搜索命中标题都走同一分段器。

## 4. 不完整/歧义时保留原文

这是实现的核心约束：

- 先把候选表达式按**括号/花括号平衡**扫描成整体；允许括号内空格。
- 只有**整个候选**都通过解析器时，才生成数学 Widget。
- 解析失败时，**整个候选**作为普通文本输出，绝不输出“前半段是数学、后半段是原文”的拼接。
- 对于没有 `**` 的复合公式，允许在**顶层运算符**处拆分，分别转换完整的子表达式（如 `mass(pi+-)-mass(pi0)`）；这不会破坏 `sin**2` 这类带上标的整体表达式。
- 再退一步，复合公式中的完整粒子名/电荷名可以单独转换（如 `G(Z --> pi0 gamma)/G(total)` 中的 Z、π⁰、γ 和箭头）；它们的边界由完整 token 匹配保证。

因此，不支持的形式会原样显示，而不是显示错误的 LaTeX。

## 5. 明确保留原文的例子

以下形式目前故意不转换：

- `Deltam(21)**2`：`Deltam` 是 PDG 文本的扁平写法，无法唯一确定是 $\Delta m_{21}$ 还是 $\Delta m(21)$。
- `a_0(980)**+0`、`pi**0+`：电荷/上标组合有歧义，且可能产生双上标。
- `CLEO-c`、`LHCb`、`Belle`、`BESIII` 等：实验/合作组名，显式白名单，不进入公式转换。`CLEO-c` 尤其容易误读成 `CLEO^- + c`，但它是一个合作组名称。
- 测量 `technique` 列里的实验缩写只展开已核对的常见项（如 `BELL`→Belle、`BABR`→BaBar、`BES3`→BES III）；`DPWA`、`HBC`、`SPEC` 等方法代码保持原码，不伪装成合作组。
- `G(...)` 只在明确是宽度函数时转为 $\Gamma$；`G(total)` 这类没有唯一约定参数仍可能保留原文。
- 含 `\frac`、多层未闭合或多重脚本的复杂片段。
- 文本中的单位如 `MeV/c**2`：保留原文；单位有自己的 `UnitLabel` 路径，不在说明文本里逐字猜。

这些片段在 UI 中仍可选中、复制；原始字段面板始终保存数据库原值。

## 6. 测试与审计

测试：

- `test/domain/pdg_math_test.dart`：`**` 右结合、括号角色、电荷、拒绝规则。
- `test/domain/text_segment_test.dart`：文本分段、空格、箭头、`$...$`、公式回退、文章词 `a/A/I` 不误转。
- `test/domain/latex_test.dart`：粒子名、`g(A)**e` 等既有样例。

对全库 105,234 条文本字段做过一次分段审计：

- 81,487 条至少含一个数学段；
- 共 375,011 个数学段；
- 数学段中 `**`、`\mathit`、空 `^{}`/`_{}` 的坏输出为 **0**；
- 其余复杂片段以原文保留。

审计脚本是一次性开发工具，不放进常驻测试；常驻测试使用上面三组确定性样例。
