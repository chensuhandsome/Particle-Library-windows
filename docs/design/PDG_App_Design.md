# 粒子数据查询应用设计方案

版本：1.1　日期：2026-10-13

详细规范：[全库内容与 128 字段映射](PDGall_Data_Atlas.md)、[衰变结构与查询详细设计](Decay_Structure_Design.md)。三份文档共同定义产品；本文件规定范围与公共行为，衰变专篇规定其结构语义。

实施入口：[首批实现任务与就绪边界](Implementation_Start.md)。先完成无损读取到真实页面的最小完整流程，再开放已核定的结构查询；未定的物理语义不能由实现者自行补全。

核心方向：从“粒子性质速查”扩展为围绕粒子、专题、衰变、测量和文献相互导航的离线工具。衰变结构浏览、产物反查与相关测量追溯属于首版核心。

## 1. 产品定位与首版边界

面向研究人员、教师和学生，提供快速、准确、可追溯的 PDG 粒子数据查询。打开应用即可查询，不要求登录；主要数据离线可用。首发 iPhone 与 Apple Silicon Mac，暂不支持 Intel Mac；随后扩展 Android、Windows 和 Ubuntu。

应用名称确定为 **Particle Library**。名称、图标和介绍不暗示 PDG 官方出品或授权背书。

首版包括：统一搜索、粒子名称识别、专题/条目目录、分类与组合条件查询、粒子详情、全部收录性质、PDG 各类汇总、全部单项测量（包括未纳入汇总者）、衰变目录与结构、产物反查及有明确覆盖范围的末态查询、相关量网络、文献搜索及反查测量、历史汇总表、修订标记、收藏/保存查询、最近查询、引用与数值复制、PDG 版本信息。已验证类别完整解释，其他类别保留数据库原文与来源入口并明确解释范围。首版交付中文和英文 UI 字符串；文献原文与官方名称不自动翻译。首版引用复制采用数据库已有的纯文本书目信息；作者在线补全与完整 BibTeX 生成归入后续功能。物理名称保留标准符号与原始名称。

“任意粒子的各种性质”指当前选定 PDG 数据快照收录的性质，而非数据库外的全部物理知识。“相关文献”首版指数据条目或测量直接引用的文献；更广泛的研究论文检索单独标为在线扩展功能。

## 2. 技术选型

推荐 Flutter + Dart + 本地 SQLite。界面、领域模型、名称解析、版本管理和平台无关业务逻辑用 Dart；SQLite 通过 `sqlite3` 的本地绑定调用。首版不增加 Rust 核心，不运行 Node/Python 服务或 MCP 服务。

| 方案 | 适配本项目的优势 | 成本与限制 | 决策 |
|---|---|---|---|
| Flutter / Dart | 五平台共享主要界面与逻辑；移动与桌面适配集中维护 | 引擎有包体与内存开销；平台手感需要主动设计 | 首选 |
| Kotlin / Compose Multiplatform | 五平台可共享逻辑和界面；Android 生态成熟 | 不同目标的工具链与运行时仍需分别验证 | 备选 |
| Swift / SwiftUI | Apple 系统集成方便 | 其他三平台需要另外的 UI 与集成方案 | 若未来仅做 Apple 才优先 |
| Rust / Tauri / TypeScript | Rust 核心与网页界面可共享 | 多语言桥接；系统 WebView 差异；移动交互需专门验证 | 当前收益不足以抵消复杂度 |

这是针对产品需求的选型，不是未经测量的速度排名。Flutter/Dart 的发布构建可采用本地机器码；SQLite 的实际性能仍取决于查询、索引、分页和数据访问方式。[Dart](https://dart.dev/overview)、[Flutter 平台支持](https://docs.flutter.dev/reference/supported-platforms)、[Kotlin](https://kotlinlang.org/multiplatform/)、[Tauri](https://tauri.app/start/prerequisites/)

数据库访问在长期存活的后台 isolate 中执行，禁止在界面线程进行大查询、导入或索引构建。`sqlite3` 当前提供五个目标平台的本地支持；具体版本与最低 SDK 在第一阶段冻结并以各平台构建验证。[sqlite3 官方包说明](https://pub.dev/packages/sqlite3)

原始 PDG 库使用显式 SQL 与类型化结果模型；用户数据库可用 Drift 管理收藏、设置、历史与迁移，第一阶段以依赖复杂度决定是否采用。不要为原始 PDG 库生成会自动改写其 schema 的迁移。[Drift](https://drift.simonbinder.eu/platforms/)

## 3. 页面与导航

### 手机

底部三个入口：查询、收藏、设置。最近查询放在查询页，避免增加导航层次。

1. 查询页：统一搜索，范围可选“全部、粒子、性质/专题、衰变、文献”；常用操作是分类浏览、条件查询和衰变查询。顶部只放搜索与范围，复杂表单进入相应子页；专题不要求先选粒子。最近查询保留已执行的查询摘要。条件筛选显式点击“查询”，不在每次改条件时扫描全部测量。
2. 粒子页：标准符号、原始名称、电荷与身份信息；主要性质摘要；性质、衰变、文献三个分区。摘要沿用同一已核验系列/官方 best summary 规则，多义时显示可选条目，不取首行。
3. 性质详情：先显示系列定义、适用范围和组级约定，再显示 PDG 汇总及“全部测量”；完整列表默认不排除未纳入平均/拟合或状态未知的值。定性、条件和非数值单元格也保留；没有浮点值不等于没有内容。每页列出本系列总条目数、当前筛选范围及纳入状态，用户可展开。
4. 测量详情：显示全部数值列、总/统计/系统误差、单位、测量条件、注释、各数值列是否用于 average 和 fit、引用；不存在的字段不补造。同一测量不同列的状态可不同。
5. 文献详情：展示数据库实际有的题名、出版信息、document_id 与 DOI/INSPIRE 等标识符；缺失字段明确显示未收录。当前快照未提供独立作者字段，离线不猜作者。首版可复制现有书目信息；后续有来源的在线补全可增加作者及更多出版细节。
6. 设置：语言、随系统/浅色/深色主题、字体大小、清除最近查询、数据版本、检查应用更新、许可、隐私、支持入口。首版更新入口打开对应应用发布渠道，不独立下载数据库。最近查询支持单项删除与全部清除；收藏支持取消，操作后可撤销。

| 平台 | 检查应用更新的行为 | 冻结时间 |
|---|---|---|
| iOS/macOS | 打开对应 App Store 产品页 | 阶段 C 商店记录创建后；未发布测试版显示“尚未公开发布” |
| Android | 商店发布则打开商店页；测试 APK 显示测试版本信息 | 阶段 D 确定商店与 app ID 后 |
| Windows/Ubuntu | 打开所有者控制的 HTTPS 发布页，显示版本/签名/安装说明 | 阶段 D 冻结具体 URL；URL 未就绪时不显示可点击更新入口 |

首版不自动下载或安装可执行更新；不得假定 Windows 已上 Microsoft Store，也不在设计阶段编造发布网址。

系统返回手势与返回按钮均有效；返回查询时保留输入、滚动位置和候选。切换粒子不会丢失收藏状态。当前 PDG 年份在详情页可见，不仅藏在设置中。

### 桌面

窗口宽度足够时采用左侧 280–340 逻辑像素搜索列表、右侧详情。详情里的测量或文献可在右侧面板展开；小窗口回到单列。初始布局阈值为 840 逻辑像素，实施时按内容和字体缩放调整，不按设备名称判断。

提供系统菜单、键盘焦点、方向键选候选、Enter 打开、Escape 关闭当前浮层、Cmd/Ctrl+F 聚焦搜索。Cmd/Ctrl+C 尊重系统选中文字；另提供明确的“复制数值/引用”操作。窗口恢复、系统分享与外部链接通过平台适配层实现；文件批量导出归入后续功能。

### 必须覆盖的状态

未输入、正在搜索、唯一匹配、多候选、无结果、未收录性质、未收录测量、文献字段缺失、无网络、更新失败、数据库损坏、旧版本已恢复。无结果与查询失败不得用同一个空列表表示；未收录不能显示为零。

### 分类与条件查询

首版提供受控筛选表单，不提供自由文本 SQL。条件用可读摘要一直显示，例如“介子；质量中心值在 1–2 GeV；按 PDG 汇总；当前版”。手机在子页面编辑条件，结果页显示摘要与修改按钮；桌面左侧筛选、右侧结果。类别、电荷、性质和范围为常用条件，量子数、纳入状态等放在可展开的更多条件中；避免把全部控件塞入固定宽侧栏。定义用物理名称呈现，内部映射键不进入用户界面。清除条件、修改单项、返回结果均保留状态。

编辑中的条件与上一次已执行条件分开保存。未再次提交时，旧结果注明“对应上次查询”；查询中和失败时不将旧结果重标为新命中。切换数据层时，仅当前层的有效条件进入新查询，保留但停用另一层的表单值；条件摘要及复制内容只写实际执行条件。

| 条件 | 首版行为 | 数据前提 |
|---|---|---|
| 粒子种类 | 介子、重子、轻子、夸克、规范与 Higgs 玻色子；保留“其他/分类未确定” | 首先解码粒子所关联 `pdgid.flags` 与本快照 `pdgdoc`，以官方 API 对照；细分类另建有来源的映射，不按名字或 MCID 猜 |
| 电荷、粒子/反粒子 | 选择实际 charge、cc_type；按具体变体返回 | 不把共享性质系列误作同一电荷态 |
| 自旋、宇称等 | 单独选择 I、G、J、P、C；仅开放已核验的结构化字段 | 不能把有多个候选或未确定的原始量子数强行变成确定值 |
| 数值性质 | 首版质量、宽度、寿命：选择可比较定义、单位及下界/上界；支持仅给一端 | 只对已核验类别提供数值筛选；其他收录性质仍可浏览，后续按类别扩展 |
| 查询数据层 | “PDG 汇总”或“单项测量”；单项模式可筛 average/fit 的纳入状态 | 两种模式不自动互相回退 |

基本分类可完全离线建立：按 `pdgparticle.pdgid_id` 连接粒子条目的 `pdgid.flags`，由该快照 `pdgdoc` 解码 B/M/L/Q/G；G 的名称保留“规范与 Higgs 玻色子”，不泛化为所有标量粒子。官方参考 API 的分类实现用于对照，API 源版本在 A2 固定。性质条目自身的其他 flags 不冒充粒子种类。[PDG 粒子 API](https://pdgapi.lbl.gov/doc/pdg.particle.html)、[分类参考实现](https://github.com/particledatagroup/api/blob/main/pdg/particle.py)

味道、粒子家族等细分类需要额外核查对应版官方 Particle Listings/Particle Properties 的分组与 PDG identifier 链接，保留版次、出处和身份核对记录。不能将章节中的混合样本、搜索项或组织性条目直接赋为单一类别，也不按 MCID 数字规则猜无编号条目。[2026 Particle Listings](https://pdg.lbl.gov/2026/listings/contents_listings.html)

A2 交付全库基本分类的确定/冲突/无映射覆盖统计与未定条目处置。未解码或矛盾标志列为“分类未确定”；仅已核验的细分类开放筛选。网页暂不可用不阻断已通过离线核查的基本分类。查询摘要显示覆盖范围，未定者仍可单独列出；筛选不可用与零命中分开表示。

首版所有条件同时满足（AND）；每个枚举字段可选择多个允许值，字段内是 OR。复杂嵌套 OR/NOT、跨衰变分支分数数值组合及按完整实验条件关联筛选放到后续。衰变末态查询使用独立表单与作用域，见衰变专篇；文献原字段搜索与系列内测量筛选属于首版，不能与跨粒子数值筛选混写。未知量子数、复杂字符串、缺失字段及确有依据的不适用状态分别显示；空值不能直接推断为不适用。有依据确认“不适用”的量子数与普通指定值比较为假，选择“不适用”状态时为真；尚未解释的空值仍为未知。条件匹配采用真/假/未知三态，默认只返回明确为真者；“同时列出尚无法判定者”开关将未知结果放在独立分区，不混进确定命中数。

AND 组合中任意条件明确为假即排除；全部为真才进入确定命中；无假但至少一个未知才进入待判分区。选择“状态未知”查询纳入标志时，null 与该枚举条件匹配为真，不能混淆“明确筛选未知状态”与“其他条件无法判定”。

跨粒子条件分成两层：表单选择全局 QueryDefinition（性质类别、可比较的物理定义、单位、summary 选择政策或测量列语义），BindingRegistry 再按快照和粒子变体映射到各自具体 PropertySeries/PDG identifier、列与 summary 行。不是把某个粒子的系列 ID 套给全部粒子，也不是只匹配 DATA_TYPE=M 就合并所有质量定义。首版只开放经过逐项核验的定义集合，例如不同质量定义分别列为选择；未建立映射的粒子保留在覆盖说明/待判区，不能声称查遍了全部定义。

BindingRegistry 的键包含快照、全局定义键、粒子变体；输出具体系列/列、适用关系、summary 选择依据和映射来源。每个性质条件独立绑定。唯一可核验映射才进行确定求值；缺失、多候选或未知定义为待判，显示原因及候选，用户可在该粒子结果内选定定义/条目形成显式覆盖绑定。覆盖绑定进入 QuerySpec 与复制摘要，仅影响该变体/性质，不改全局默认规则。全局筛选列出映射覆盖状态，不把未覆盖当不存在。

按 PDG 汇总查询：在上述每粒子已绑定系列的所选 edition 中筛选。采用 §5 的严格 best summary 规则，并先确认变体及定义适用；无唯一首选时显示全部候选并要求显式选择，不按数组首行选 fit/average。仅当全局定义集合可比较时一起做范围筛选与排序；若后续增加“各粒子首选质量但混合定义”的浏览模式，应按定义分组并独立说明，不在首版暗中提供。没有汇总者标为缺少汇总，不转用单项测量。

按单项测量查询：条件在具体性质系列、数值列和测量值层求值。命中结果显示粒子、定义、具体列、原始显示值/单位、average/fit 状态及文献。若存在一个符合条件的测量值，粒子即命中；同一粒子的多个符合值折叠为一组，但可展开全部符合证据和回到本系列全部测量。若查询同时要求质量与宽度等不同性质，采用“每个条件分别存在一个符合值”，不能声称这些值来自同一次实验；显示各条件的不同证据。要求同一次实验的关联查询不在首版范围。

单项模式提供两个独立筛选器：“用于 average”和“用于 fit”，各可选不限/是/否/状态未知。布尔 false 是未使用，null 是未注明，不互相替代。两标志均明确 false 只表示“本 listing 中 average、fit 均未使用”，不能据此声称未影响任一种汇总。不能仅因 average=false 就排除 fit=true。默认两个筛选器均不限，完整数据可浏览。

测量对所选粒子变体的适用性先求值，再与数值列/纳入条件组合。`pdgmeasurement.charge` 保留原始文本；不能直接等同于 FLOAT 型 `pdgparticle.charge`。依据已核验的官方编码、系列定义和映射建立适用关系：明确匹配为真；明确其他电荷/状态为假；不可解析或范围不清为未知。charge 空白时，仅在系列对变体的适用范围已有唯一官方依据时继承该范围，否则待判；测量自身的明确限制优先。区分实际电荷、粒子/反粒子状态和官方 CP-charge 系列标志，不将其当同一种编码。官方明确共享/组合的测量只映射到有依据的允许变体，并标注共享范围与来源；不因系列共用或 charge 空白就广播为所有变体。summary 同样使用经核验的变体适用映射。

完整列表提供“当前变体已确认适用”“适用性待判”“同系列其他变体”分组，默认全部可访问、不按 average/fit 删行；原始 charge 和完整数值列保留。明确不适用的行不能进入该变体的查询命中；待判行显示系列级来源，不冒充当前变体专属测量。

每个单项条件的存在量词按证据三态聚合：任意适用性与列条件都明确为真的值使该条件为真；无真且至少一个未被明确排除的候选为未知，则为未知；全部候选明确不符合则为假。绑定/数据覆盖已确认但无收录值属于未知（缺少测量），不当作物理否定；只有明确不适用的已有候选时为假。先记录缺失/排除原因，再按 AND 组合，不用裸 SQL 空集吞掉未知。

首版数值比较默认只用普通点测量的原始中心值，在统一维度/单位后按已填写的含边界条件比较；单位换算误差和边界浮点表示按 §11 检验，不按舍入显示字符串比较。误差不改变默认命中条件。不提供“误差区间相交”默认选项；后续开放前必须定义总/统计/系统误差的选取和缺失处理，不隐式合成误差或当置信区间。

数值字段与显示层分开：`display_power_of_ten`、`display_in_percent` 不再次乘到已按字段定义解释的 `value` 上。单位文本未知、缺少中心值或不满足明确换算定义时，该数值条件为未知。已填写边界必须是有限实数；两端填写时下界不大于上界，采用含边界比较；只填写下端表示大于等于，只填写上端表示小于等于。两端都空则不启用该数值条件，不把空白解析为零；无效输入在提交前提示。首版不提供开区间运算符。同一性质最多一个数值区间，不允许把不同列/定义的范围暗中合并。

上下限、范围与排除区间不作为普通中心值参与数值范围筛选，而列为“本条件尚无法判定”。用户可按原始结果类型浏览；对 limit 类型的数值逻辑筛选放到专门验证后开放，不把一个上限自动理解为质量中心值。精确量子数/类别等其他条件仍可正常匹配。

排序只在统一物理定义集合、单位与数据层内进行，具体系列可因粒子不同而不同；未知/多值不猜排序值。单项粒子组按名称排序，组内值按绑定列排序。结果计数明确区分粒子变体数、全局唯一源值行数和变体—源值关系数；一个共享值可对应两个变体，但全局源值只计一次。多脚注只扩展附件，不扩张证据数。首版支持复制查询摘要与当前命中证据，不添加 CSV 批量导出或计算功能。

数值输入旁、结果页和复制摘要均写“只比较中心值，误差不参与；限值/缺失/适用性未定者另列待判”，以及定义集合、实际绑定、数据层、单位、快照和纳入条件。关闭待判展示时仍显示待判数量/存在提示，避免“零个确定命中”被误读为全部排除。

## 4. 名称识别

目标支持标准名称、Unicode、上下标、常用英文名称、中文名称、常见 LaTeX、历史别名、MC 编号与 PDG 数据标识符。编号模式在界面明确区分，不能把所有整数当成同一类 ID。

PDG identifier 可能指向粒子、性质、衰变或其他数据条目。精确编号匹配按真实条目类型打开，并保留上下文，不强行解释为粒子；没有特定所属粒子的量可在条目页原文浏览，不能为其编造粒子身份。

处理顺序：保留原始输入 → 解析符号和物理身份 → 精确匹配 → 已验证别名 → 前缀/包含匹配 → 近似拼写候选。规范化属于搜索过程，不修改数据库原始名称。

| 输入类型 | 预期行为 |
|---|---|
| `π⁰`, `pi0`, `pi^0`, `\pi^0` | 识别同一中性粒子的常见写法 |
| `J/ψ`, `J/psi`, `Jpsi` | 通过别名进入同一条目 |
| `proton`, `质子`, `p` | 显示质子候选；上下文歧义仍保留 |
| `B_s0`, `B_s^0`, `Bₛ⁰` | 保留味道、下标与电荷信息 |
| `anti-proton`, `反质子`, 反粒子符号 | 明确显示反粒子身份 |
| `D*`, `K`, `Lambda` | 如果缺电荷、激发态或其他身份信息，显示候选，不自动选中 |
| 拼写错误 | 提示“可能是”，不能自动跳入错误粒子 |

希腊字母大小写有物理含义，例如 Λ 与 λ、Ω 与 ω 不得无条件合并。星号、横线、正负电荷、括号质量、激发态和径向量子数都不能作为无意义标点删除。用针对物理名称的解析规则与候选身份核对取代全局 lower-case。

别名表由官方名称与条目映射、可审查的常用别名组成；中文别名单独注明来源与维护版本。历史名称可能跨版本改变归属，不能把旧名称永远绑定到当前实体。对多义别名保留一对多映射。

别名种子集是第一阶段交付物，包括数据快照全部标准名称和已有别名的导入、常用英文/中文/Unicode/LaTeX 写法、来源、适用版本及明确的歧义标记。冻结至少 100 个代表性查询及预期候选身份，分为唯一、歧义、拼写错误、不存在四类；所有标准名称与官方映射另做自动回查。唯一与歧义的身份要求逐项正确，不用平均命中率掩盖错误跳转。第二阶段补足首版声明的常用别名，未知写法正常提示候选或无结果；不承诺识别所有可能字符串。

用户输入默认是字面量。LIKE 中的 `%`、`_` 和转义符，以及 FTS 中的引号、星号和操作符要分别转义，不暗中开放 SQL/FTS 查询语言；来自转义文本的多重反斜线作为兼容候选处理，普通 LaTeX 示例保留单反斜线。

候选显示标准符号、原始名称、电荷/反粒子状态、MC 编号（如有）和解释，例如“匹配常用别名”。默认只自动完成搜索文本，不因模糊匹配自动打开详情。清晰唯一的精确匹配可按 Enter 直接打开。

## 5. 数据模型和物理语义

领域对象包括：Entry/Topic、ParticleIdentity、PropertySeries、SummaryValue、Measurement、MeasurementCell、InclusionFlags、DecayMode/DecayToken/DecayExpression、RelatedQuantity、Reference、Footnote、SectionText、DataEdition、QueryDefinition、BindingRegistry、VariantApplicability、QuerySpec、QueryMatchEvidence。MeasurementCell 保留数值/定性结果/条件文字三类内容，兼容已有 MeasurementValue 名称但不能只容纳浮点数。Measurement 与其各数值列分开，InclusionFlags 在 MeasurementValue 层分别保存 average/fit 的 true/false/null。QuerySpec 固定快照、全局定义、逐粒子绑定/显式覆盖、列、单位、数据层及条件语义；证据保留具体值、适用依据与引用。用 PDG 条目编号、版本及必要的 variant 字段定位；不同数据库中的行 ID 不视作跨版本永久身份。

性质页先按原始条目树枚举全部相关性质，再按已支持类别解释；不能只硬编码质量、宽度、寿命，也不能以是否有 summary 行或粒子身份行作为枚举门槛。空 data_type 和 SEC 均保留实际条目；专题、组织性标题、未映射粒子与普通性质分别路由。层级中的节标题与实际性质分别保留，不能遇到节标题就停止向下读取。未知类别可显示原始标题和条目链接，标明当前无法解释的字段；不把未知编码猜成已知物理含义。第一阶段形成表、字段、类别和支持状态的覆盖矩阵。

性质分区按类别分组，所有收录的结构化性质都有可访问入口；可展开全部条目并按标题/定义筛选。筛选无结果不等于粒子无此性质。测量分页时保留定义、列标题、单位与来源版本，返回后恢复展开与滚动位置。

SQL 按各表实际声明的整数外键关联：引用 PDG identifier 的数据表用其 `pdgid_id` 连接 `pdgid.id`，名称/衰变项按各自 `pdgitem` 外键连接，测量引用用 `pdgmeasurement.pdgreference_id` 连接 `pdgreference.id`，测量值按其测量外键连接；选择汇总时明确 edition，不仅靠字符串 PDG identifier 匹配。外键断裂、重复或多义关联显示数据错误或候选，禁止静默取首行。

脚注采用 schema 的实际关联例外：单项测量通过 `pdgmeasurement_footnote.pdgmeasurement_id`/`pdgfootnote_id` 整数外键关联；列表/章节级脚注可按 `pdgfootnote.pdgid` 与当前快照唯一的 `pdgid.pdgid` 精确字符串关联，区别于其他表应使用整数外键的规则。`footnote_index` 是局部显示/排序信息，不作为全库唯一键，也不用于猜测某个 summary 行的脚注。该字符串没有数据库外键保证，缺失/孤立/多义关联保留原文并明示归属未定，不靠前缀或数字接近补连接。

脚注不经 `pdgid_map`、别名、前缀或序号间接归并到其他条目；无法精确关联的脚注保持归属未定，不以关系链“修补”为确定脚注。

`pdgdata` 没有脚注外键：只显示它自身 comment，以及有确定关系的所属章节脚注；按所属标识列出的脚注标“本节脚注索引”，并显示它们实际挂接的测量，不能冒称每条脚注都适用于整节或某个汇总。组级定义优先取 pdgtext 和经核查的官方说明。若官方原文有更精细引用但 SQLite 未表达，提供原文入口，不自动解析文本序号为隐藏外键。

当前版来自 `pdginfo` 的 edition 与发布 metadata；summary 行的 `pdgdata.edition` 必须与所选版本明确匹配。NULL 不自动补成当前版，显示“条目版次未注明”并进入待判/原文浏览；只有官方语义明确并完成核查后才允许其他适用映射。测量无独立 edition 列时绑定其快照 listing 年份，不借其引用年份伪造历史 listing。

保留 PDG 的显示文本、原始数值、正负误差、单位、上下限/区间、置信水平、汇总类别、数据定义、测量列、脚注及来源版本。平均、拟合、推荐值、上下限和单项测量使用文字标签，颜色不作为唯一判别。

质量与宽度的不同定义或测量系列分别列出；不能只根据“mass/width”选第一条。不能把单项测量冒充 PDG 汇总，不能丢弃同一次测量的其他列。衰变保留父子层级、缩进、比例及包容/排他关系，不擅自相加或补足总和。

默认使用完整的 PDG 显示对象：舍入文本、显示十次幂或百分号、单位、结果类型和必要的置信水平。`display_value_text` 不包含十次幂和百分号，不能直接拼上单位就称完整值：非百分显示补上非零 `display_power_of_ten`，百分显示按官方编码显示 `%`，不再叠加同一个 −2 幂。完整的 `value_text` 若已含幂，不再重复补幂。未知/矛盾显示编码保留原文并提示未解释；屏幕、读屏与复制共用同一格式化对象。[PDG 汇总显示字段](https://pdgapi.lbl.gov/doc/pdg.data.html)、[测量显示字段](https://pdgapi.lbl.gov/doc/pdg.measurement.html)

上述字段也可能不足以恢复原表的全部显示语境。质子模式 `S016.22` 的摘要只有 `>10000`、无数值/单位/尺度；关联 `S016T22` 的汇总却给出不同的文本、原数值和 years 单位。两条记录分别展示并注明关联，不跨记录借值、单位或置信水平拼接；BR 类型也不能排除该量实际为寿命。表头单位只有在同版来源确认后才作为显式语境加入显示对象；未确认时保留原文并标明缺少的语境。具体处置与用例见衰变专篇。

换单位时以原始数值和误差进行一致转换，换算值与新单位单列显示，同时保留 PDG 原文及原单位，可一键恢复。只支持有明确维度映射的单位；自然单位与 SI 的推导换算留到独立验证后的后续版本。缺少数据与数值零严格区分。[PDG schema](https://pdgapi.lbl.gov/doc/schema.html)

保留正负误差与统计/系统各分量；不调用会将非对称误差取平均的便利接口，也不再次将 `scale_factor` 乘到已存储误差上。首版不自动在寿命与宽度之间推导，不将无数据推断为寿命无穷，不自动组合不同实验结果，不自动填补量子数或衰变。引用复制分为“PDG 汇总来源”和“实验文献来源”，不把两者混成一条。

### PDG 汇总与完整测量

“官方首选”在一个已绑定系列、明确 edition 内按官方参考实现的严格选择规则定义：全部 listing summary 恰有一行时采用该行；有多行且 Summary Table 内恰有一行时采用那一行；其余情况无唯一首选。多条 listing summary 且没有 Summary Table 行时仍保留全部汇总，不能把 API 返回的 None 解释为无数据。多候选通过明确选择解决，禁止使用非 pedantic 模式的首行回退。这只是系列内选择规则，不替代质量定义或变体适用性核查。[best_summary 定义](https://pdgapi.lbl.gov/doc/pdg.data.html)、[选择参考实现](https://github.com/particledatagroup/api/blob/main/pdg/data.py)

fit、average、选定限值、估计、由相关量得到的值等按当前版 `pdgdoc` 和官方定义分别标注，不能将所有 `pdgdata` 条目通称 average；`in_summary_table` 仅指是否出现在 Summary Table，不表示某实验被用于平均。

当前快照的 `pdgmeasurement_values.used_in_average` 与 `used_in_fit` 是分别存在、允许缺失的字段。完整测量读取不带“只取纳入”隐含条件；是否使用的状态显示在各数值列旁。测量折叠行可写“部分列用于平均/拟合”，但必须展开到原始列，不能给整篇论文统一的 included/excluded 标签。一个值用于 fit 但未用于 average 是合法组合，保持两标志原貌。

“未用于平均/拟合”不等于“测量错误、质量较低或 PDG 否定”。原因只来自实际注释/脚注；未说明就写“未注明原因”。两个 false 标志也不证明该文献的其他数值未被使用，不用它作论文级质量评价。

平均/拟合标志按本快照的测量 listing 解释；历史 summary 值不附带完整历史纳入关系。切换到历史 edition 时，不把当前测量标志套到旧平均/拟合。首版以当前快照 listing 查询全部测量；历史版仅显示实际可用的汇总，并明确缺少相应历史测量关联，禁止伪造。

不能只凭使用标志建立“此值参与某个具体 fit summary 行”的精确链接；数据没有表达这种关系时，标签只说本系列 listing 中用于 fit/average，不假装掌握拟合协方差或完整输入组合。[PDG 数据与测量结构](https://pdgapi.lbl.gov/doc/schema.html)

## 6. 文献与原文

离线显示数据库中实际存在的书目信息、文献标识符和它关联的测量。首版提供题名词语、document_id、DOI、INSPIRE 标识及发表年份检索；以引用表为全集，不要求文献必须被当前测量引用。通过文献回到具体测量和系列，再经相关量关系回到衰变。点击标识符通过 HTTPS 链接打开外部浏览器，链接从已核验标识符和允许的供应方 host/path 模板生成，拒绝任意 URI scheme 与数据库内的可执行链接。没有 DOI/arXiv/INSPIRE 标识符时仍保留原始引用，不造链接。

首版保证纯文本引用复制，不要求用户联网。2,283 条引用在当前快照没有测量反向链接，也仍然可检索。DOI/INSPIRE 标识存在多条引用记录共用的情况，引用记录以快照和 pdgreference.id 区分，去重文献展示只形成可展开组，不删除源记录。

后续在线补全和 BibTeX 导出逐项核查字段，记录供应方与获取时间，不改写原始 PDG 引用；缺项保留原文并明确注明，不能猜题名、作者或年份。

PDG reviews、完整解释性正文和数据库未收录材料提供官方原文入口。`pdgall` 包含历史 Summary Table 数据不等于完整的历年测量与综述全文；覆盖情况需要逐类检查。[PDG 数据文件说明](https://pdg.lbl.gov/2026/api/index.html)

本快照 `pdgreference` 有 document_id、题名、出版名称/年份及 DOI/INSPIRE 字段，未提供独立 author 列。不能从 document_id 或题名猜完整作者列表。出版名称可能已含期刊缩写、卷期或页码，原样显示，不因没有分拆字段就丢弃。无作者或其他完整字段时，只复制已收录信息；后续 BibTeX 如信息仍不全，明确标为草稿，不称完整引用。

## 7. 视觉方向

采用安静、清晰的学术工具风格：冷灰背景、深墨文字、蓝色主要操作、少量青色辅助信息。数值和误差是视觉重点，避免渐变、玻璃效果、大面积装饰、每种粒子不同颜色或营销式大标题。

图标方向：深墨蓝圆角底上的白色展开书本与青色粒子轨道，轨道上有一颗白色粒子；无文字，使用自有几何图形。暂不使用 PDG 标志、机构标志或暗示官方认可的图案。现行母版与渲染脚本见 `internal/brand/`。

链接保留可识别的文字或下划线；选中同时用位置/勾选标记。上限、平均、拟合等语义使用文字，不做红绿正确/错误编码。系统高对比度模式增加轮廓，减少动画时取消非必要动效。

### 字体、排版和尺寸

正文用各平台系统 UI 字体；中文跟随系统中文字体。粒子符号和少量公式必要时捆绑具适当许可的数学字体（候选 STIX Two Math），逐项检查 Greek、上下标、横线和反粒子标记，不依赖平台恰好有某个字形。

Flutter 中普通标题和数值用可选择文本；复杂符号可用局部数学组件，但必须提供纯文本复制和可访问名称。数据库标题、注释与 TeX 名称先作为数据处理；数学组件只接受已支持的语法子集，不执行任意 HTML、脚本、外链或 TeX 指令。渲染不支持时回退可选择的原文并注明，不能删掉导致身份改变的符号。数字采用等宽数字特性，不把整段正文改成等宽字体。

手机初始正文 17 逻辑像素，次要文字 15，主数值 22–26，页标题 24–28；桌面正文 15–16，主数值 20–24。系统字体缩放优先于固定尺寸；200% 时内容重排，不能裁切误差或单位。

采用 4/8/12/16/24/32 的间距体系；手机两侧边距 16，桌面 24。圆角约 10–12，阴影仅用于浮层。手机触控目标至少 44×44 逻辑像素，Android 适配采用至少 48×48；桌面按钮可较紧凑但焦点明确。

数值换行优先保证“值 + 误差 + 十次幂/百分号 + 单位”完整；长测量在手机按块展开，不强行塞进横向多列表格。桌面可用表格，单位与列定义始终可见。复制文本保留正确符号和数据年份。

## 8. 离线存储与更新

三个存储区域：只读 PDG 原始快照、可再生成的搜索索引、独立用户数据库。索引包含标准名称、别名、变体和搜索键，绑定源数据库哈希、别名版本、分类/定义映射版本及语义规则版本；不会改写 PDG 原库。

第一版随安装包附带当前已验证的数据库和预生成索引；首次启动无需强制联网下载。首次复制写入暂存文件，校验后原子启用；中途退出时重新验证/复制，不能留下看似已安装的半份数据库。不把全部测量加载进内存，按粒子、性质与页面分页读取。

原始快照或索引损坏时先隔离故障文件，从包内已验证资源恢复；恢复不覆盖用户库。用户库迁移前保存一个可回退副本，收藏增删采用事务；启动检查损坏时保留原文件和最近有效副本，提示选择恢复，不静默清空。无可用副本时仍可用只读 PDG 查询，明确收藏暂不可用。此机制仅防已定义的故障，不承诺在设备丢失时恢复；云同步不在首版范围。

更新流程：用户查看版本/下载大小 → 下载暂存文件 → 校验来源与完整性 → 校验 schema/metadata/必需查询 → 生成或加载匹配索引 → 原子切换。当前查询固定在同一数据库版本，旧连接退出后再清理旧文件。磁盘空间不足、下载中断或验证失败时保持旧数据可查询。

官方 HTTPS 来源与在发布时冻结的可信 manifest 是来源约束；哈希用于完整性和版本绑定，单独从同一未验证位置下载哈希不能证明真实性。若提供自有更新服务，manifest 需签名并固定公钥，密钥轮换另行设计。首版优先随应用更新数据库，独立在线数据库更新放到阶段 E，避免把未部署的更新服务作为首发前提。

用户收藏跨版本迁移需验证条目是否仍存在、名称或身份是否变化；无法确定时显示“需要重新选择”，保留原收藏，不自动改指向。应用版本、PDG edition、数据库 release/哈希分开显示和管理。查询、历史和缓存绑定快照及映射/语义版本；相同年份但内容不同的快照不共用索引。更新同时验证代码、schema、索引、映射的兼容关系；旧映射不能读取未经核验的新库。历史查询重跑先展示版本差异，需重新选择的绑定不能静默替换。

可选用户导入官方 SQLite：首版默认关闭此入口。开放前通过系统文件选择器复制到应用容器，以只读模式打开，禁用扩展加载，设置 `trusted_schema=OFF`，启用绑定可提供的 defensive 选项，按已支持 schema 白名单检查；所有查询由应用预定义，不执行输入库提供的 SQL、视图、触发器或脚本。设置拟定 256 MiB 文件上限、有界结果数和 5 秒校验/查询中止预算，超限拒绝并说明原因。超时必须由经验证的 SQLite 原生进度中止或 interrupt 能力落实，并实测执行中断、连接状态和后续查询；界面 Future 超时、丢弃结果或 isolate.kill 不能直接作为同步 FFI 已中止的证明。阶段 A 验证冻结绑定能否落实这些选项与中止；不支持时继续关闭入口，不能把转储重建当成无风险替代。官方数据库下载也先验证来源/完整性再打开。保持 SQLite 安全更新，不提供任意 SQL 控制台；损坏与不支持版本的恢复在存储层定义。[SQLite 安全](https://sqlite.org/security.html)

应用进入后台或被系统终止不保证任务继续运行。短事务及时提交；复制/未来下载使用可恢复暂存状态。回到前台重查快照和连接状态，失败保留上次有效数据，不能显示未完成切换已成功。

## 9. 架构与模块

建议模块：`app`（导航/主题）、`domain`（类型与语义）、`data`（PDG SQL/版本/引用）、`search`（解析/索引/排序）、`features`（页面）、`platform`（文件/分享/链接/菜单）、`user_store`（设置/收藏）。UI 不直接拼 SQL；数据库对象和行 ID 不直接作为 UI 状态。

新增 `query` 模块负责 QuerySpec 校验、类别映射、三态匹配、谓词编译和结果证据；查询层分别生成 summary 或 measurement 的只读参数化查询，字段名/运算符取白名单。不同性质采用分别存在匹配证据的条件，不能用错误的 SQL join 拼成同一项测量。计数、分页和导出式复制使用同一快照与 QuerySpec；用稳定键排序/翻页，避免多值/多文献 join 扩张造成重复计数或漏行。

稳定分页键包含快照、粒子变体、实际系列、源表和值行 ID；全局源值计数按快照、源表和源值 ID 去重，不能把不同表同 ID 当同一值。共享证据关联另计。附件通过测量/引用/脚注 ID 加载，不改变主证据行集合；逐页拼接需与原始身份—证据集合一致。

每个后台数据库连接由单一持有者管理。名称索引使用单独的轻量 isolate 与只读连接，避免被同步的全量测量查询阻塞；待执行查询合并为最新请求。取消旧请求须分别记录“尚未执行”“执行已中止”“仅丢弃返回”，不冒称底层工作已停止。查询参数绑定，请求/响应带快照和 QuerySpec 标识，切换版本时不混合旧查询与新查询结果。界面层保留明显的错误类型而非吞掉异常。

依赖原则：SQLite、状态管理、路由、外部链接/分享、必要字体即可；不为小功能加入大型通用框架。冻结 lockfile 与构建工具版本，维护依赖许可清单。首版代码许可证由项目所有者决定，数据与第三方依赖的许可分别保留。

## 10. 性能目标与验收方法

以下是拟定的体验预算，不是已有测量结果。第一阶段用 release 原型与真实库作可行性测量，阶段 B 用最终页面与后台队列复测；调试构建不能作为验收依据。

| 观测量 | 初始目标 | 计时边界 |
|---|---:|---|
| 本地名称查询 | P95 ≤ 100 ms | 从提交查询到候选就绪；防抖等待另记 |
| 输入到候选显示 | P95 ≤ 250 ms | 包含拟定 120 ms 防抖与绘制 |
| 粒子详情首屏 | P95 ≤ 250 ms | 已安装、索引可用、打开粒子到首屏可读 |
| 组合条件查询首屏 | P95 ≤ 500 ms | 显式提交至首屏结果、确定/待判计数就绪；当前快照、首版有限条件集合 |
| 冷启动可输入 | 5 次冒烟检查每次 ≤ 2 s | 进程启动到输入可接受；逐次列值与最大值，不以 5 样本声称 P95 |
| 首次启动可查询 | ≤ 5 s | 包括资源复制；若超预算给明确进度 |
| 稳态内存 | 暂以 ≤ 250 MiB 为上限目标 | 明确测量进程/运行时口径；按平台分别记录 |

基准设备拟为一台 iPhone 12 或相当性能设备、一台 Apple Silicon Mac；由可获得设备最终确定，未覆盖的设备不标通过。后续各平台增加各自参考设备。至少 100 个覆盖不同名称类别的预先冻结查询，固定三轮；报告逐轮和总体样本数、P50/P95/最大值，冷热分开，不选最佳一轮。五次冷启动只作冒烟检查并列所有样本；若需启动尾延迟决策，再事先冻结至少 30 次样本和 10 分钟硬时间盒，报告经验分位数及有限样本局限，不能超时自发加精。

阶段 A 同时记录快照/索引/发布包体积、首次资源复制的磁盘占用、更新后首次查询和长测量列表连续滚动 30 秒的帧耗时与掉帧；帧预算按设备刷新率确定。250 MiB 内存是初始预算，分别记录平台工具的整个进程口径与可获得的 Dart heap，不能混为一个指标。字体放大与文本选择手势也参与长列表检查。

初始体积预算：Apple 发布构建产物目标 ≤ 200 MiB，应用容器首次复制/索引的额外占用目标 ≤ 160 MiB，分别与工具报告的商店下载/安装大小分开记录。这是产品预算，不是声称商店存在同数值的限制。新旧数据并存时按两份数据库与两份索引及暂存文件计算所需空间，空间不足不开始切换。若真实 PDG 数据增长或平台产物超过预算，先查重复资源与不必要字体，再在阶段 A 明确调整与原因；不删除数据类别或减损误差/文献来满足体积目标。

搜索不全库逐行读入 Dart。先用精确键/别名表和索引，再在有限候选内做近似匹配。预生成索引是否采用 SQLite FTS 由运行环境实测决定；FTS 不能直接承担所有带标点的粒子身份解析。

达到体验目标即停优化。若失败先检查查询计划、分页、数据传输和线程阻塞；只有证实 Dart 中的某一计算热点占主导，才提出 Rust 或其他本地核心，并用同输入/同输出测量收益。

## 11. 数据与交互验收

建立数据类别覆盖表，明确每个 table/字段/编码的处理方式。按类别设置对照样例：稳定粒子、反粒子、共用 PDG 属性的电荷态、宽共振、混合/特殊状态、上下限、非对称误差、多列测量、衰变比例与嵌套衰变、缺失文献标识符、历史版本。

至少包括 π⁰、质子/反质子、J/ψ、不同电荷的 D/D*、B_s、K_S/K_L、Λ/Ω 与容易混淆的希腊小写输入，以及不同质量定义的粒子。样例具体 PDG 条目由真实快照枚举并确认，不预设某数据一定存在。

验证链：原始 SQL/官方 API 与页面字段逐项对照；官方 API 只作参考，不嵌入应用。固定参考源码版本，启用 pedantic 语义；性质枚举明确 `require_summary_data=False`，读取 `summary_values(summary_table_only=False)` 和全部测量/全部数值列。不用便利的 mass/lifetime/error 等结果替代原始行集，避免默认筛掉无汇总性质、自动推导或对称化误差。页面复制结果重新核对；不存在的身份和故意混淆电荷的负例应被拒绝或要求选择。原始文本要求逐字一致；数值转换以数学误差预算与显示末位约束验收，不用宽松百分比掩盖错误。

全支持类别做数据到领域模型的自动对照，重点类别再做屏幕和复制的人工样例检查。只有被检验的数据类别可声称已支持；未支持类别能给来源入口但不能伪装成解释完整的数据。

界面检查：浅/深色、所有 token 配对、VoiceOver、键盘导航、中文/英文、字体 200%、320 逻辑像素窄屏、长名称、长误差、长引用文本、多测量分页与展开返回位置、文本选择/滚动手势、无网首次启动、随应用升级后的数据启用、复制中断和损坏恢复。后续增加在线更新时再验收下载中断。示意图中的未验证物理数值只能用字段标签或空位，不能借视觉设计发布未经核验数字。

测试只围绕上述失效方式和产品流程，不扩展成无关 benchmark 或全生态测试。无实现前，设计审核不等于数据、性能或发布验收完成。

### 条件查询与完整测量的验收

全库分类映射、量子数解析和 summary/measurement 查询分别建覆盖矩阵：说明哪些是原始字段，哪些来自已核验映射，哪些只保留原文。字段类型、状态未知、不适用和多候选量子数必须有明确反例；I/J 不按字符串字典序排序，半整数用确定性离散值解析，复杂原文不猜值。

对全部收录测量检验 Measurement→各 MeasurementValue→文献/脚注关联与分页完整性。每个已支持系列的全列表与原始 SQL 行集核对，不先按纳入状态过滤；按值行分别检查 average/fit 的九种 true/false/null 组合。真实快照缺少的组合用明确测试 fixture 覆盖，不声称为 PDG 实测数据。同测量多列、混合使用状态、重复文献、共享性质的粒子/反粒子、未注明原因均要显示与复制一致。

冻结不少于 40 个查询语义用例，独立从原始 SQLite/可核查分类映射得到预期身份和证据集合，核对粒子变体及具体测量值，不能只比较数量。其中必须覆盖：summary 与 measurement 命中不同；无汇总但有测量且禁止回退；某值 average=false/fit=true；null 标志；量子数未知与有据不适用；区间两边界、单端边界和两端留空；不同单位等价输入；percent/幂显示完整且不重复缩放、非对称/统计/系统误差不被平均、缺数据显示不被推导成寿命无穷；上限/区间结果；AND 含真/假/未知；不同性质来自不同测量；同列双区间的输入拒绝；历史 summary 与当前 listing 状态隔离。不得为了得到预设结果而删测量或改单位。

同一查询须包含两个粒子使用不同具体系列 ID 的实例、同类别不同定义禁止混并、全局定义无唯一绑定及显式覆盖、特定电荷测量不得命中其他变体、charge 空白且无法确定适用范围时待判、空白但系列适用范围唯一时有据继承、显式测量限制覆盖系列范围、官方共享范围、无真但有未知候选、edition NULL、重复脚注/共享证据与相同名称分页边界。核对变体—值对及全局源值两种计数。类别映射和解码矩阵另包含 `data_type`/`mode_number`/`flags`、`scale_factor`、`measurement.charge` 编码和来源；不把 scale_factor 当单位乘子。

矩阵记录每张表/字段的消费者与展示位置：`pdgitem_map` 用于名称候选及通用名称/衰变项的一对多展开，`pdgid_map` 用于有来源的条目间关系（例如分支比与分支分数），`pdgtext` 用于节标题和包含物理约定的解释段落，`pdginfo` 用于快照元信息，其他表同样逐项列出用途。衰变中的 X、anything 等包容项保留原文，不强制映射成具体粒子；关系映射不意味着可以据其自动计算另一个量。A2 枚举 edition NULL 和 charge 值域，记录来源规则、分布及未解释项；来源不足的编码继续待判，不因枚举了字符串就称已理解物理含义。官方 best summary 政策统一采用 §5 严格规则，不另外发明 fit/average 优先表。`in_summary_table` 需与候选数量共同判断，不单独作为 best 标志。

best summary 唯一性键为快照/edition、粒子变体、已绑定性质系列与定义。矩阵记录候选 summary 行 ID、适用依据、官方文档/参考源码版本和结论；全库自动枚举零行、唯一行、多行但唯一 Summary Table、多 Summary Table 行以及多 listing 行但零 Summary Table 行。后两种都不能静默取首行，最后一种不能显示无汇总。定义/变体多义仍需单独处理；官方唯一汇总若为限值也不变成中心值。`pdgdata.value_type`、`pdgitem.item_type`、`pdgmeasurement.technique/place` 也明确列入解码矩阵，不用显示排序决定物理优先级。

所有必覆盖场景维护“场景→用例编号→原始预期身份/证据→检查结果”追溯表，至少 40 个用例不是用例数量代替场景覆盖；每个必覆盖场景须对应至少一个具名用例，未覆盖者不能验收。

脚注用例包括整数关联的测量脚注、精确字符串关联的章节脚注、不同章节重复 footnote_index、NULL/孤立 pdgid、同章多个 summary 行。对照归属和附件集合，确保章节说明不广播成专属脚注、缺关联不静默丢弃。

衰变与脚注使用实际快照中的 `pdgdecay`、`pdgfootnote`、`pdgmeasurement_footnote` 及相关条目映射。阶段 A2 对完整 schema 清单逐表核查，衰变的比例/分支比与层级通过相应性质和 decay 映射关联；未知编码保留原文。

数值范围比较遵守数据库存储精度，不通过加宽用户区间来消除边界错误；确有表示误差时由阶段 A2 给出统一比较规则及单位等价/边界负例，规则必须在界面说明中可解释。性能用例另冻结 20 个首版合法条件集合，固定三轮、报告经验 P50/P95/最大值与样本数，最多 10 分钟；达到预算即停止，不自发扩展复杂 SQL 或全平台 benchmark。

## 14. 第一阶段完成后的决策

A0 可先准备环境；A1/A2/A3 结束后确认数据访问、定义和衰变表示规则，再扩大界面实现。B1/B2 用实际页面确认六项：常用搜索和专题是否可达；分类/条件查询语义是否明确；衰变目录、阶段和末态反查是否正确；相关量及全部测量是否完整；数值/误差/限定/文献是否可追溯；手机/Mac 交互与 release 性能是否达标。技术栈可行性在 A1 以原型决定，避免完整开发后迁移；最终页面验收不会提前记在数据准备阶段。

暂定选择：Flutter/Dart、离线随包数据库、冷灰/墨蓝主题、三入口手机导航、双栏桌面布局。Mac 目标固定为 Apple Silicon，当前不安排 Intel 支持。正式品牌已确定为 Particle Library；最低系统版本、完整中文别名覆盖、首发地区、最终代码许可证和可选联网功能在第一阶段明确。

## 15. 从全库内容确定的信息架构

### 15.1 数据规模与身份层级

当前设计依据 `pdgall-2026.0.sqlite`：15 张表、128 个字段、22,049 个 PDG 条目、1,170 条粒子记录、43,872 条测量、49,080 个测量单元格、14,594 条文献。汇总数据有 352,047 行，其中 2026 年 19,587 行；历史记录跨 54 个实际版次标签，覆盖最早 1958 至最新 2026，但早期很稀疏。

计数口径分别是条目、粒子记录、测量、单元格和引用记录，不能把它们混称为“粒子数”或“实验数”。名称项有 3,270 条，也不等于 3,270 个粒子。全字段及各类别分布见[数据内容与功能映射](PDGall_Data_Atlas.md)。

| 对象 | 来源 | 最小独立页面 | 是否要求具体粒子 |
|---|---|---|---|
| 条目/专题 | pdgid、pdgtext、父子关系 | 定义、子项、说明、相关数据 | 否 |
| 粒子身份 | pdgparticle 及所属条目 | 名称、电荷、量子数、性质、衰变 | 是，且可能要消歧 |
| 性质系列 | 有汇总/测量或可定义的 pdgid | 定义、汇总、完整测量、历史 | 否 |
| 衰变模式 | BF 条目与参与项/关系 | 结构、汇总、相关量、测量 | 母项可能是混合样本/通用名称 |
| 测量 | pdgmeasurement 及全部 values | 值列、条件、脚注、文献 | 依系列适用范围 |
| 文献 | pdgreference | 书目信息与反向测量 | 否 |

统一页面路由先查实际条目，再决定页面类型；数据域的 Entry 可以没有 ParticleIdentity。查到条目但缺粒子行时仍能打开条目页。当前 `M169` 为 PART 条目而没有粒子行，不能以“无粒子匹配”遮蔽其质量和宽度条目。

### 15.2 不能漏掉的专题

475 个根节点中有 37 个没有粒子行。其中既有专题，也有目录标题和缺身份映射条目，不能统一贴“其他粒子”。首版专题目录至少区分以下实际内容：

| 专题入口 | 代表条目 | 呈现方式 |
|---|---|---|
| 中微子性质/混合/种类数 | S066、S067、S007 | 参数/限制及系列定义；不虚构所属单粒子 |
| 双 β 衰变 | S076 | 核素、方法、半衰期等完整列；不同核素不混排为一个量 |
| 轻夸克联合性质 | Q123 | 质量与比值定义、尺度/约定说明 |
| CKM 矩阵元 | S052 | 原始定义、系列、测量及引用 |
| B 混合样本 | S049、S051 | 样本组成可见，禁止赋给单一电荷态 |
| b 重子混合样本 | S061 | 共享样本限制和来源 |
| 暗物质与新粒子搜索 | S030、S055、S064、S077 等 | 模型/质量/置信水平等条件完整显示 |
| 新态与家族标题 | M300、M209、B801 等 | 有子项则列实际子项，空标题保留原文入口 |

顶层相邻标题并不必然由 parent_id 连到后面所有粒子。对无子节点的家族标题不能凭相邻排序划定物理成员；需要有出处的额外分组，未建立时只显示目录文字和官方链接。

### 15.3 信息到达路径

默认从任务进入：找粒子、找某量、找衰变、找文献。每种结果都可以切换到相邻对象：粒子→系列→测量→文献，衰变→相关量→测量，文献→全部相关测量→原系列，专题→参数/搜索条件。

所有核心信息以离线原始数据为基础。网上的完整说明、综述及论文作为来源扩展；界面不因无网把已收录脚注或测量隐藏。外链失败只影响外链，不影响本地导航。

## 16. 性质浏览和完整测量的具体交互

### 16.1 性质目录

粒子详情先显示少量常用摘要，然后给出可搜索的原始性质目录。可提供已核验的中文组名，但原始标题与定义保持可见。以下为分组词汇，实际分组取决于条目内容：

- 质量、质量差、宽度、寿命及不同定义。
- 电荷、磁矩、电偶极矩及粒子/反粒子比较。
- CP 破坏、混合参数、振幅模/相位及强相位。
- 形状因子、斜率、衰变参数及耦合比。
- 极点、残数、Breit–Wigner 参数与光子振幅。
- 搜索限值、排除区间、模型或实验条件。
- 未归类量与原始章节。

这些不是把 data_type 一对一翻译成菜单：空 data_type 下也有大量实质测量，同一个有代码的类别也可能有不同定义。原始条目树在分类视图之外始终可打开。

### 16.2 一个系列的详情

固定顺序为：完整定义与路径→适用粒子/样本→约定说明→全部 PDG 汇总候选→当前版完整测量→相关条目→历史汇总→来源与复制。组级说明过长时显示首段和显眼的完整入口；影响定义的关键限定在数值附近可见。

对 pole 与 Breit–Wigner 等多定义，目录并列显示，详情顶部保留定义标签。切换系列不是换单位；历史和测量列表随系列切换，不能保留上一系列的值再只改标题。pdgLive 的 [N(1535) 页面](https://pdglive.lbl.gov/Particle.action?home=BXXX005&init=0&node=B063)显示了这种多定义需求。

### 16.3 多列测量

本库有 2,270 条多列测量，最多 6 列。数据对象把同一 measurement 的所有 values 视为有序单元格组；值行身份包含自身 ID 与 sort，不能用 column_name 作唯一键。

| 列的用途 | 实际列名例子 | 展示与查询原则 |
|---|---|---|
| 主要观测量 | VALUE、MASS、WIDTH、MODULUS、PHASE | 根据系列和单位解释，不选固定首列 |
| 模型预测/参照 | STD. MODEL | 与实测量区分，不当成第二条实验 |
| 置信水平/限值 | CL%、LIMIT | 作用范围须明确，不从相邻数值推断 |
| 实验条件 | BEAM、ENERGY、sqrt(s)、METHOD | 与结果同屏，不能从复制中删去 |
| 样本信息 | PARTICLE、ISOTOPE、CHG、MATERIAL | 文本字段可有物理意义，即使 value 为 NULL |
| 计数/背景 | EVTS、BKGD EST | 保留原列，不与主结果误差自动合并 |
| 其他说明 | COMMENTS、空列名 | 按原序保留；空名显示“未命名列”且原始字段仍为空 |

手机先显示主结果摘要和文献，再展开完整字段卡片；若主结果角色未确定，直接以有序列卡片展示。桌面按每个系列实际列形状成表，不用全库固定六列强行拼接。误差、限定和文献可以展开，但原始完整记录始终可达。

总误差、统计误差、系统误差原样并列；不存在的分量显示未提供，不自动补零。模与相位同时存在不代表可得到复数协方差；不同列的数值也不自动组成一个拟合输入向量。

### 16.4 系列内筛选

首版支持文献年份、document_id、已收录 technique 原码、average/fit 状态、限值类型、是否带修订标记。所有筛选显示在结果摘要，随时恢复“全部”。未知 technique 以原码显示；place 的 N/U/L/B 不能在解释之前转成纳入状态或实验地点。

如果筛选命中某一列，返回整个 measurement 组，突出符合条件的列，同时保留其他列；查询证据计数按符合值行计，显示记录数按 measurement 计。仅用参考文献 ID 不能认定两条不同系列记录来自同一个实验数据样本。

### 16.5 定性与缺数值结果

区分“有数值”“只有源文本”“有字段但为空”“未收录该系列”四种状态。当前库存在 seen、searched for、no limit feasible，以及数值字段为空但文本包含限值的记录。首版不重新解析字符串制造可用于数值筛选的中心值；原文显示不能因 value=NULL 而消失。

`limit_type=NULL` 也不能单独证明它是可比较的点测量：还需有有限数值、可解释单位、适用定义和有效列角色。range/exclusion 不从中间值伪造成点估计。

## 17. 历史汇总和当版修订

### 17.1 首版历史表

性质和衰变详情提供“历史汇总”表，列为版次、原始定义标识、完整显示值、单位、结果类型、是否 Summary Table、comment。一个版次可能多行，必须展开全部或保持分组，不能按版次去重取首行。

版次选择只列该系列实际存在的 edition；没有记录标未收录，不插值、不将上一版值延续填充。保持原始单位，并可另外显示经核验的统一单位列。历史 title/粒子身份/结构无单独版本字段时写清“当前条目说明；数值属于所选历史版次”。

用户同时查看两个年份时提供并排表，显示各自定义/类型/注释差异。默认不计算显著性和相对拉力：相邻 PDG 版次可能共享实验输入，库中没有跨版协方差。值不变也不能断言没有更新输入。

### 17.2 历史趋势图的开放条件

后续图只接受经核验的同定义、同单位、同适用态数值；同年多候选分别展示或要求选择。上下限用箭头，范围用区间，文本结果单列，缺版次留空。禁止把限值边界与中心值用一条线连成“测量趋势”。

即使同 PDG identifier 跨版相同，也需核对量的定义、原注释和适用范围；数据库不能提供的历史语境应明确列出。首版历史表足以利用旧数据，趋势图不是首发前提。

### 17.3 当版修订

当前 metadata 有 `changebar_start_date=2025-09-01`；1,899 条测量、1,081 条脚注带 changebar。详情可显示“当版标记为新增或修订”，并在解释中给出快照和起算日。脚注改动不等于数值变化，标记不能区分新增与修改，也不代表发现日期。

`pdgid.year_added` 在本库全部为空，因此不提供基于它的“新发现粒子”“今年新增性质”榜。以后如果数据更新，应核查字段语义后再开放。后续真正的版本差异需要两份完整快照比较，不能仅从 changebar 重建历史。

## 18. 全局搜索、文献与收藏

### 18.1 多对象搜索

| 输入 | 查找对象 | 匹配规则 |
|---|---|---|
| 粒子名称/常用符号 | 名称项、粒子行及已核验别名 | 精确和候选路径优先，保留大小写含义 |
| PDG identifier | 任意条目 | 按真实类型打开；带 edition 时只对实际历史数据生效 |
| MC 编号 | 粒子行 | 与条目标识区分；无号粒子不被目录排除 |
| 性质/专题词 | 条目 description、pdgtext | 先匹配标题，再给说明文本片段 |
| 衰变名称或产物 | 模式原文、名称项关系 | 文字命中与结构匹配分区 |
| DOI/INSPIRE/document_id | 引用表 | 精确标识优先；格式识别不会凭空创建记录 |
| 文献题名词或年份 | 引用题名/发表年份 | 字面查询，范围限定在实际收录文献 |

“全部”结果按对象分组，各组显示独立数量与“查看全部”；不把 100 条测量当成 100 个粒子候选。原始记录冲突必须显示所属条目和定义，不依靠搜索排序替用户决定。

名称缩写与文本检索的中文支持分开：首版中文 UI 完整，已维护中文别名可查；不承诺自动翻译全部性质和文献题名。未知中文词可以提示英文/符号搜索，无结果不能伪造翻译后的命中。

### 18.2 文献页

显示当前库字段原貌：题名、PDG 文献短标识、出版信息、年份、DOI/INSPIRE 链接。可按粒子/专题和系列分组列全部反向测量，显示每组记录数。没有关联测量的文献保留详情，说明“本快照没有关联测量行”。

同一 DOI 的多条记录可视为“同标识记录”分组，但各 document_id、题名和测量端点仍保留；不根据 DOI 相等直接删除勘误、不同版本或重复录入记录。若缺题名，以 document_id 为标题，不用相邻记录补值。

引用复制分两种：所用 PDG 汇总的版次引用，或该单项测量的原文引用。当前快照 citation 不能自动用于全部历史版本；历史版确切书目未收录时复制版次和条目定位，并提供官方引用入口，不能编造完整历史引用。

### 18.3 收藏和保存查询

收藏支持粒子、专题/系列、衰变、测量与文献；保存查询支持粒子条件和衰变结构条件。可按用户自定义标签分组，首版可先只提供平列表与类型筛选，标签作为小步增强。

收藏记录至少包含目标类型、源快照、源对象键、PDG identifier、必要的粒子身份字段、用户显示名及创建时间。测量/文献的整数键不能直接跨快照使用；更新时核对系列、原引用标识、列形状/原内容等候选，无法唯一确定时保留旧定位与原显示并要求重新选择。

保存查询记录完整 QuerySpec 和规则版本，不仅是界面输入文本。最近查询记录时间与当时快照；再次打开默认展示原条件，用户提交后才产生新结果。所有收藏与历史留在设备，默认不联网同步。

## 19. 数据读取与应用接口契约

### 19.1 领域接口

接口返回显式成功/未收录/多义/不支持/数据错误状态，不能统一成空数组。下列为职责定义，不要求依赖某个代码生成框架。

| 接口 | 输入关键项 | 返回关键项 |
|---|---|---|
| `search` | 查询文字、对象范围、快照、分页 | 分类型候选、匹配理由、总数或明确未完成计数 |
| `getEntry` | 条目定位与历史选择 | 原定义、类型、父路径、子项及数据可用性 |
| `resolveItem` | 名称项、身份规则版本 | 全部直接身份/映射路径、唯一或多义状态 |
| `listProperties` | 粒子/专题、包含未知类别 | 完整条目集合、支持状态、原始分组 |
| `getSummaries` | 系列、edition、适用态 | 所有候选、严格首选判定、完整格式化对象 |
| `listMeasurements` | 系列、列/状态筛选、分页 | 整组 measurement、全部 cell、命中列、脚注/引用定位 |
| `getDecay` | 模式、快照 | 原始参与项、已核查阶段、目录父子、相关量 |
| `queryDecays` | DecayQuerySpec | 真/假/未知集合、覆盖、逐模式证据 |
| `getReference` | 引用记录定位 | 实际书目字段、反向测量、标识冲突组 |
| `listHistory` | 系列 | 可用 edition、各年全部记录、定义可比性状态 |

请求和响应均带快照及规则版本。UI 在版本或查询标识不一致时丢弃旧响应，保留明确加载状态；这不等于原查询底层已经取消。

### 19.2 数据对象不以便捷数值为中心

格式化对象同时带原始字段、可读文本、单位、结果类型、误差分量、置信水平、来源定位以及解释状态。数值仅在可比较情况下单独用于筛选；屏幕和复制使用同一对象。

历史 summary、当前 listing measurement、衰变结构和在线补全分别带各自版次/来源。不同表相同整数 ID 不构成同一对象；SourceRef 固定快照、表名、行键。相关量/别名/目录边保留来源边键，不仅保存最终目标。

### 19.3 本地索引设计

派生库至少包含名称候选、条目搜索、祖先路径、来源覆盖、全局定义绑定、衰变结构/未解析项、相关量双向表和文献查找键。使用原库已有索引先实现，只有查询计划和实测证明必要才增加派生索引。

全文搜索的备选是 FTS5 与固定字段词索引。冻结 SQLite 是否启用 FTS5、分词器与中文行为；中文不可靠时使用受控别名/字面子串候选，不把未验证分词结果当完整检索。题名/说明原文不因分词而更改。

原库 pdgdata 的 edition 和条目索引是分开的，跨系列历史查询可能需要派生复合键；不得在只读原库直接增加索引。新派生结构每次由同一快照生成，可删后重建；生成失败保留旧版本配对，不能启用半份结构。

### 19.4 错误与可恢复行为

| 状态 | 对用户的含义 | 行为 |
|---|---|---|
| 无名称候选 | 当前检索范围没有命中 | 提示改范围/写法，保持输入 |
| 有条目无身份 | 条目存在但无具体粒子映射 | 打开条目页 |
| 有文本无数值 | 源库有信息但不能数值比较 | 原文展示，数值条件待判 |
| 身份或定义多义 | 有多个不同候选 | 列出差异和来源，不自动取首行 |
| 结构部分可解释 | 只支持部分语法 | 原文和已确认部分可用，精确条件按三态求值 |
| 源关联异常 | 整数/字符串关系不一致 | 保存可读取的原始内容并说明关联失败 |
| 不支持 schema/编码 | 当前应用无法解释 | 不启用新库；未知编码保留可读原文并计入覆盖 |
| 查询中止/失败 | 未取得完整结果 | 不将部分结果标为全部；重试保留原条件 |

## 20. 能充分利用数据库的功能优先级

优先级以离线信息价值、现成数据支持和解释成本决定；“数据库有字段”只说明可开发，不能替代语义验收。

| 功能 | 数据基础 | 用户价值 | 安排 |
|---|---|---|---|
| 全目录与专题 | pdgid、pdgtext | 避免只查得到有 MC 编号的粒子 | 首版 |
| 多定义性质 | 类型、标题、flags、测量 | 区分不同质量、宽度和实验条件 | 首版 |
| 衰变结构与深层目录 | pdgdecay、parent_id | 读清模式关系、多重数和限定 | 首版重点 |
| 产物反查与结构条件 | 名称映射、阶段解释 | 从目标末态找过程 | 首版重点，有明确支持覆盖 |
| 相关量网络 | pdgid_map | 从 BF 找到实际比值/宽度/寿命测量 | 首版重点 |
| 多列测量及完整脚注 | measurement、values、footnote | 保留数值的物理语境 | 首版 |
| 文献反向目录 | reference→measurement | 找某篇论文在 PDG 中贡献哪些记录 | 首版 |
| 历史汇总表 | edition | 查看某量的已收录历年值 | 首版 |
| 修订提示 | changebar、metadata | 定位当版新增/修改的测量/脚注 | 首版 |
| 保存查询/模式 | 独立用户库 | 重复使用常见粒子和末态条件 | 首版 |
| 测量比较图 | 数值、误差、类型、条件 | 查看分布与 PDG 汇总位置 | 后续；先固定相同定义与全部行 |
| 历史趋势图 | 历史汇总 | 看可比较量的演变 | 后续；缺版、限值和多候选分别呈现 |
| 多粒子比较表 | 已核验定义绑定 | 同类参数并排 | 后续；每列来源和适用范围可见 |
| CSV/JSON/LaTeX 导出 | 完整领域对象 | 研究与教学复用 | 后续；原始/解释字段分开，转义公式/表格输入 |
| BibTeX 与在线文献补全 | DOI/INSPIRE + 在线数据 | 补齐作者和书目 | 后续；按需联网且标来源 |
| 两份完整快照差异 | 官方旧库和新库 | 可靠追踪数据修改 | 后续；不能从当前库推造旧结构 |
| 独立数据更新 | 官方源/可信 manifest | 不随应用升级也能换版 | 后续；签名/兼容/回退先验证 |

不开发自动补全衰变总和、自动“最优实验”排名、自动平均不同模型、自动判断新发现、自动重做 PDG 拟合等没有足够输入依据的功能。查询可以帮助找到比较对象，不能以 UI 暗示不存在的统计结论。

| E22 | 54 个 edition 标签 | 只列实际年份，各年多行保留 | 插值和同年首行去重须失败 |
| E23 | 历史汇总 + 当前测量 | 版次来源分别标记 | 当前纳入标志套历史须失败 |
| E24 | year_added 全空 | 无发现年份断言 | 补造新增年份须失败 |
| E25 | changebar | 新增/修订且有起算日 | 脚注修改误称物理值改变须失败 |
| E26 | BF* 的直接测量为零 | 沿关联量找到已有测量 | 空 BF 测量列表误称无实验须失败 |
| E27 | 相关量 G/T 端点 | 原定义/单位保持 | 强转 BR/BF 须失败 |
| E28 | subdecay_id 全空 | 不虚构显式级联关系 | parent_id 当粒子衰变边须失败 |
| E29 | 19 个无 outgoing 模式 | 原文可读、结构待判 | 精确空末态命中须失败 |
| E30 | 含 T/多箭头/耦合电荷模式 | 按已核验作用域解释 | 跨阶段 EXISTS 拼接须失败 |

衰变专篇进一步给出真实条目标识及查询负例。名称至少 100 个、普通条件至少 40 个、衰变查询至少 30 个具名用例；数量是组织下限，全部声明场景都要有覆盖。已存在的源数据场景与合成稳健性场景分开。

本快照 average/fit 组合只有 `(false,false)`、`(true,false)`、`(true,true)`，没有 `(false,true)` 或 NULL。版次 NULL、孤立脚注、非空 subdecay_id 在本快照也没有真实实例；仍需用明确标记的合成负例检查兼容策略，不能宣称从当前 PDG 样本验证过这些情况。

数据行集合、关联身份、原文本、结构图边和计数要求精确相等；单位转换按支持单位及其误差预算检查。每一种新比较图/导出列/结构关系都视为新的展示对象，先核查它的定义和源值，再加入页面。
