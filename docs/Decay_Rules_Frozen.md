## 1. R1 唯一身份（D1 核心）

**输入**：单箭头模式；outgoing 参与项的 pdgitem 行及其直接/映射身份。

**规则**：
- R1a `P` 型参与项：`pdgparticle.pdgitem_id = item.id` 恰一行 → 该粒子
  身份（含电荷态与 cc_type；fixture 记录完整粒子行身份——同一
  listing 可承载多行，如 K⁺/K⁻ 共享 S010，只记 listing 会丢失电荷）。
- R1b `A`/`W`/`S` 型（别名/旧名/快捷）：沿 `pdgitem_map` 展开；展开终点
  为唯一 `P` 且满足 R1a → 该身份，且记录"经别名 item#"路径。展开终点
  仍是别名链（环）或指向非 P → 不满足 R1，整模式待判。
- R1c `G` 型（通用名，不区分电荷）：**不满足** R1（多个电荷候选）；
  归 D2。R1 候选集因此排除含 G 型 outgoing 的模式。
- R1d 一个模式内同一 item 多行或多行同 item：身份以多重数合并（见 R2），
  不视为歧义。
- R1e `pdgparticle` 行数 ≠1 的 item（如 item 1593 → B185+B205 两条
  listing，设计 §4.1 身份冲突）：该 item 身份待判·identityConflict——
  D1 查询只对产物侧求值；母项身份同样按 R1a/R1b 规则解析，解析失败
  仅使"按母粒子限定"的查询待判，不影响产物侧三态。

**预期（fixture 例证，全部由数据推导）**：
- `S043.6` `W+ --> pi+ gamma`：pi+/gamma 在本快照均为 P 型且各恰一行
  粒子记录（R1a 唯一）——正例（首批文档曾误把 gamma 当 G 型；数据
  修正：本快照 gamma 是 P 型 item id=1）。
- `S032.1` `D0 --> K- pi+`：K-/pi+ 唯一（R1a）。
- `S035.214` `tau- --> pi- K0S K0S nu_tau`：K0S 为 S 型，经
  pdgitem_map 解析到唯一 listing（R1b 别名路径）。D1 全集内 457 个
  A/S 型参与行在本快照 100% 唯一解析、零环零歧义（W 型 outgoing 在
  D1 中 0 次出现，规则分支保留但无数据可测）。
- 反例 `S043.1` `W+ --> e+ nu`：**nu 是 G 型**（通用中微子名）→ R1c
  不满足，模式不属 D1、归 D2 待判——绝不猜具体中微子。
- 反例 `S035.286`（多箭头）：D1 之外，跨阶段旁观粒子不得合并。

## 2. R2 重复数（多重数）

**规则**：
- R2a 参与项行的 `multiplier = m`（m ≥ 1）表示该身份产物计 m 个。
- R2b 同一**已确认阶段**、同一确定身份、同一适用条件下的多行（同 item
  或别名并归后）且无冲突条件 → 数量相加（设计 §4.2 原文条件；跨阶段
  同名行不得合并，S035.286 反例）。
- R2c 数量断言（查询）："至少 k 个 X"= 合并计数 ≥ k；"恰好 k 个 X 且
  无其他"须同时满足 R3b（排他完整）。
- 禁止结果：`S009.1`（π⁰→2γ，单行 multiplier=2）不得去重为 1 个光子；
  不同身份的两行（`S032.1` K⁻ 与 π⁺）不得合并计数。

**fixture**：`S009.1`（×2 单行）、`S032.1`（两个不同身份各 1）、
`M002.131`（分组乘数 '2(pi+ pi-)'：逐行 multiplier 为权威，括号组是
显示层未解析片段，绝不二次应用）、`S035.286`（跨阶段同名行——多箭头，
不属 D1，作反例钉死不合并）。

## 3. R3 明确包容项（Inclusive）

**规则**：
- R3a `I` 型参与项（X/anything）= "存在未列出的其他产物"；它**不否定**
  已明确列出的成员，也**不证明**任何未列出粒子存在。
- R3b 含包容项的模式**永不判"恰好"**：完整性断言一律 `未知`，原因
  `inclusiveRemainder`。
- R3c "包含查询"（至少这些产物）在含包容项模式上正常判定：明确列出
  部分按 R1/R2 求值；若所查产物只能来自"未列出"部分 → `未知`。

**fixture**：从 208 个 d1_inclusive 模式取例；反例：不含 I 的
完整模式才可判"恰好"。

## 4. 查询语义（D1 范围）

- 作用域：单阶段 = 参与项全部属于唯一箭头阶段（描述恰一个 `-->`）。
- 三态：`真`（全部断言成员明确满足）、`假`（某断言成员被明确列为不同
  身份且无包容项可容它）、`未知`（含包容项/含未解析片段/身份歧义）。
- 三态计数守恒：真+假+未知 = 作用域模式总数（fixture 逐模式核）。
- 跨阶段禁止：多箭头模式不参与 D1 求值（整模式 `未知·multiStage`），
  防止把第二阶段产物当作第一阶段末态（`S035.286` 反例）。
