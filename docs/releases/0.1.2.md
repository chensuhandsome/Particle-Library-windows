# Particle Library 0.1.2

Public preview update for macOS and Android.

## New and improved

- **Mobile export works** — JSON notes, Markdown notes and full ZIP backups now
  open the Android/iOS system share sheet instead of calling the unsupported
  desktop save dialog. Import works on all platforms.
- **Full backup import** auto-detects ZIP or JSON, validates the backup version,
  merges notes without deleting current data, and never overwrites the Apple
  Supporter entitlement.
- **Capture safety** — pressing Enter in the capture search no longer appends to
  the first unrelated note.
- **Cleaner search results** — global note hits use the current UI language and
  the same title/fallback rules as the Notes page.
- **MathML title search** — when raw SQL cannot match a query split across
  MathML nodes, cleaned reference titles are searched as a fallback.
- **Full catalog everywhere** — desktop top bar and compact overflow menu.

## Fixed in this preview line

- Highlight anchor removal persists; saved highlight ranges no longer clobber
  custom titles.
- Tapping a highlight opens its range handles directly; range save has error
  handling, desktop handles are enabled, and deletion asks for confirmation.
- Review anchor chips open the correct PDF page.
- Spaced exotic-particle names stay whole; prose suffixes are not swallowed;
  neutral charge-zero shorthand is a superscript; `~` masses, decay
  multiplicities and text-only arrow tokens render correctly.
- Reference titles strip MathML/JATS markup safely, including pretty-printed
  MathML and literal comparison signs.
- Android no longer requests the Billing permission; Supporter stays Apple-only
  and hidden until an App Store product is configured.

## Verification

- `flutter test`: **199 passed**
- `flutter analyze`: clean
- iOS Release compiles (`--no-codesign`); public iOS distribution still needs a
  paid Apple Developer team.
- macOS preview remains ad-hoc signed and **not notarized**.
- Android arm64-v8a smoke-tested on API 35; API 24 and armeabi-v7a APKs are
  built but not device-tested here.

## Final fixes in this re-release

- Nested script labels such as `K_{{{{\mathit \ell}}4}}` now typeset as
  `K_{\ell4}^{\pm}`.
- Multi-quark subscripts follow PDG Live spacing (`T_{cc\bar c\bar c}`,
  `T_{c\bar c1}`) without thin-space artifacts.
- Text captures include a short quote in the default title; the capture dialog
  shows the note anchor, and related notes include incoming note-to-note links.

## Known remaining limitations

- macOS preview is ad-hoc signed and **not notarized**.
- iOS is development-signed only; App Store distribution and the Supporter
  product need a paid Apple Developer team.
- Android API 24 and armeabi-v7a APKs are built but not device-tested here.
