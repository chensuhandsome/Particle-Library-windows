# Particle Library 0.1.3

Update for macOS and Android. The macOS preview remains ad-hoc signed and is
**not notarized**.

## Navigation

- A persistent top bar now provides **Back** and **Forward** across each tab's
  own navigation stack; switching tabs preserves where you were.
- In the Search split view, the detail pane keeps its own history. Back follows
  the topmost visible stack, and Forward restores the stack that last lost a
  page.
- **Settings now returns to the page that opened it**, including a detail page
  or a page already open in another tab.
- Keyboard shortcuts: `⌘[` / `⌘]` on macOS, `Alt+←` / `Alt+→` elsewhere.
  Android/iOS system back is routed through the same stacks.
- Page-level duplicate back arrows were removed for tab pages; the persistent
  top bar is the single navigation control.

## Zotero

- Added one-click **Add to Zotero** for INSPIRE records and PDG reference
  records through **zotero-inspire 4.1.0**'s own save-target picker.
- The app brings Zotero forward for the picker and returns to Particle Library
  after the picker closes.
- Clear setup guidance when Zotero is running but zotero-inspire is missing or
  too old: the exact status is shown in Settings, with an install/update action;
  clicking Zotero at a reference opens an actionable dialog instead of silently
  copying BibTeX.
- The Zotero item cache now lives inside the Zotero integration card, and its
  automatic-update switch starts enabled.
- The Zotero mark is a quiet, theme-aware `Z` chip rather than a heavy solid
  brand block.

## Math and reference titles

- Descriptive titles such as `pi ELECTRIC POLARIZABILITY alpha(pi)` are no
  longer mistaken for one giant particle subscript.
- Reverse-related measurement formulas now typeset `ABS(...)` as absolute
  value, `Gamma`/`G` as `Γ`, `delta**K` as `δ^K`, numeric coefficients such as
  `2pi+`, and compact labels such as `K*(892)-`, `K0S`, `D_10` and `D_20`.
- PDG compact star/charge forms (`D^**0`, `D^(*)+`) are supported in reference
  titles.
- Snapshot titles that end mid-sentence (for example `Dalitz Plot Analysis of`)
  are completed once from Crossref when possible and cached locally; offline
  they are shown with an explicit ellipsis.
- Reference titles with MathML/JATS markup continue to be cleaned and
  typeset without leaking tags.

## UI and fixes

- DOI and INSPIRE actions are now labelled simply **DOI** and **INSPIRE**;
  full explanations remain in their tooltips.
- The duplicate Zotero button in the reference action row was removed; the
  top-right Z button is the single entry point.
- Settings shows the installed app version next to **Check for updates**.
- The reviews page opened from a particle/category no longer pre-fills its
  search box with a related query; category PDF filtering still works.
- Fixed tab-local history after opening global pages, and made Settings return
  to the exact previous page.

- macOS preview is not notarized; first launch may require the documented
  Gatekeeper bypass.
- iOS App Store distribution still requires a paid Apple Developer team.
- Android API 24 and 32-bit devices are not device-tested in this release.
